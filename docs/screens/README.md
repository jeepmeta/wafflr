# Screen design workspace

This directory is the canonical place to review Wafflr's mobile screens and image-asset needs before feature implementation.

Start with [the screen catalog](./screen-catalog.md) for the inventory and [the Markdown wireframes](./mockups.md) for simple, editable layout sketches. The wireframes use basic React JSX and inline styles as visual references only; they are not production components and require no images or real styling. Use the [screen-to-asset plan](./asset-plan.md) to map existing artwork to actual UI needs and reduce redundant files, and the [review checklist](./review-checklist.md) when reviewing layouts.

The Markdown wireframes are the canonical mockup reference. Do not create a second mockup format or generate replacement art until the current asset library has been inventoried and mapped to the screens.

The repository's current tracked tree does not include the full existing asset library, so exact duplicate detection and final keep/replace/retire decisions remain pending until those files are available.
