# Screen design workspace

This directory is the canonical place to review Wafflr's mobile screens and their image-asset needs before feature implementation.

Start with the [screen catalog](./screen-catalog.md) to review every screen and state, then open the individual SVG mockups in [mockups/](./mockups/). Use the [screen-to-asset plan](./asset-plan.md) to map existing artwork to actual UI needs and reduce redundant files. Use the [review checklist](./review-checklist.md) when evaluating each mockup.

The mockups are draft wireframes, not approved production UI. Keep one source of truth for the screen inventory and one source of truth for the asset plan. Do not create a parallel set of mockups or generate replacement art until the current assets have been inventoried and mapped to the screens.

The repository's current tracked tree does not include the full existing asset library, so exact duplicate detection and final keep/replace/retire decisions remain pending until those files are available.
