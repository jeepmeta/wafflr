Wafflr screen mockups

Static, mobile-first visual references for the native app. These are layout mockups, not a browser game or production UI. Character and branded-artwork slots are placeholders until the existing asset library is audited.

Design intent: playful, chunky, polished game UI; consistent component shapes; reusable art assets; native text for dynamic content. The examples use temporary emoji and labeled placeholders, not approved final artwork.
