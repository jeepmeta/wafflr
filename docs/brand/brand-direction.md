# Brand direction

## Personality

Wafflr should feel playful, friendly, lightweight, fast, and polished—more like a tiny social game than a conventional utility. Butters, the cute waffle mascot, is a recognizable emotional anchor.

## Visual direction

- Chunky cartoon / arcade-game interface.
- Bright, warm food-inspired colors with clear contrast.
- Branded raster WebP assets for buttons, panels, badges, icons, and character art.
- White-background source/export assets for the current generator workflow; do not create checkerboard transparency previews or baked-in drop shadows for those exports.
- Native text and layout for dynamic content; avoid rendering text into reusable artwork when it must change at runtime.
- Keep control shapes and labels consistent across device sizes; scale and reposition the layout rather than changing button shape or wrapping labels unpredictably.
- Mobile-first, vertical stacking on compact screens; wider arrangements on larger screens when it improves clarity.

## Interaction principles

- Butters can welcome, encourage, react to ties, and celebrate the winner.
- Animations should be short, purposeful, and respect reduced-motion settings.
- Minimize instructional copy. The UI should explain itself through hierarchy and feedback.
- Avoid visual clutter and generic corporate dashboard patterns.

## Token status

The current token values in `@wafflr/design-tokens` are placeholders. Do not present them as a finalized brand palette. Update tokens and this document together when the product owner approves a brand system.
