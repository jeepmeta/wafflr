# Wafflr landing page

This app is reserved for a lightweight public landing page that explains Wafflr and links to the iOS App Store and Google Play when the app is available.

It is not a browser game and must not implement room creation, joining, deck editing, voting, or results. Keep the page fast, accessible, mobile-responsive, and consistent with the approved brand assets.

The workspace is intentionally not implemented yet. Add a package manifest and framework only when the landing-page implementation is the next planned stage.
